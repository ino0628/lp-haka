樹木葬と永代供養は比べる物ではない。納骨先を選ぶ順番と、契約書で見る6つの項目

2026年 最新版執筆・監修 墓じまい案内所事務局

結論

樹木葬は「お墓の形」（墓石の代わりに樹木や草花を目印にして焼骨を埋蔵する）、永代供養は「管理の仕組み」（承継者がいなくても墓地や寺院が供養と管理を続ける）で、比べる対象ではありません。永代供養が付いている樹木葬や納骨堂が多くあります。実際に選ぶときに効くのは形の名前ではなく、「個別に安置される年数」と「合祀後に遺骨を取り出せないこと」の2点です。個別安置の年数は13回忌・33回忌まで、契約から10年、公営では20年など施設ごとに違い、都立霊園の規則は他の遺骨と共に埋蔵した遺骨は返還しないと定めています。平均購入額は樹木葬71.7万円、納骨堂81.5万円、一般墓152.0万円（鎌倉新書2026年調査）。最初から合祀する形は最も安く、公営では1体5.3万〜5.8万円（都立霊園の合葬埋蔵施設・直接共同埋蔵）です。

墓じまいで遺骨の行き先を探し始めると、「樹木葬」「永代供養」「納骨堂」「合祀」という言葉が並んで、どれを選べばいいのか分からなくなります。最初に整理したいのは、樹木葬と永代供養は比べる物ではないということです。片方は形、片方は仕組みの名前です。この記事では、言葉の整理、費用の平均、そして選ぶときに本当に効く2つの点と、契約書で見る項目を解説します。

そもそも何が違うか

言葉 何の名前か 意味
樹木葬 お墓の形 墓石の代わりに、樹木や草花を目印にして焼骨を埋蔵する
納骨堂 お墓の形 屋内の施設に焼骨を収蔵する（法律上は都道府県知事の許可を受けた施設・墓埋法2条）
永代供養 管理の仕組み 承継者がいなくても、墓地や寺院が供養と管理を続ける
合祀（合葬） 埋蔵の方法 他の方の焼骨と一緒に埋蔵する。骨壺から出すので個別には取り出せない

「永代供養」「樹木葬」「合祀」は法律の用語ではなく、契約上・商慣行上の呼び名です。法律（墓埋法）が定義しているのは「納骨堂」「墳墓」「改葬」などで、焼骨は「埋蔵」または「収蔵」と書き分けられています。

樹木葬や納骨堂には永代供養が付いている物が多くあります（付いているかは施設ごとに違うので、契約書で確かめます）。だから「樹木葬か永代供養か」という問いは成り立たず、正しくは「樹木葬（永代供養付き）か、納骨堂（永代供養付き）か、最初から合祀する永代供養墓か」です。

同じ調査で、購入したお墓の47.4%が樹木葬でした。この平均額に何が含まれるかは調査では公表されていません。刻字料や納骨法要のお布施が別途かかることがあるので、見積の内訳で確かめてください。

最初から他の方と一緒に埋蔵する合祀型は最も安く、公営では遺骨1体5.3万〜5.8万円から（都立霊園の合葬埋蔵施設・直接共同埋蔵）。ただし申込資格や募集時期の制約があり、戻せません。

年間の管理料があるかどうかも違います。管理料は、永代供養付きの区画では不要か、個別安置の期間だけかかるという形があります（都立霊園の合葬埋蔵施設・樹林型は管理料なし）。一般墓は毎年かかります。

ここまでの目安で、いちど見積を取ってみますか。

選ぶときに効くのは2点

形の名前で選ぶと、後から戻せない後悔につながります。効くのは次の2点です。

  1. 個別に安置される年数。「永代」は永久ではありません。13回忌・33回忌まで、契約から10年、公営では20年など、施設ごとに違います（東京都霊園条例施行規則9条の3は、20年間個別に埋蔵し、その後は他の遺骨と共に埋蔵すると定めています）。年数は契約書に書かれています。
  2. 合祀後は取り出せない。合祀は骨壺から出して埋蔵するため、後で「別の場所に移したい」と思っても個別には取り出せません。都立霊園の規則でも、他の遺骨と共に埋蔵された遺骨は返還しないと明記されています。最初から合祀する形は最も安いですが、戻せない選択です。

なお、樹木葬という名前だけでは個別安置の有無は決まりません。都立霊園の樹林型合葬埋蔵施設のように、樹木の下でも最初から他の遺骨と共に埋蔵する形があります。名前ではなく、上の2点で見分けてください。

この2点が分かれば、「安いから合祀型」「木があるから樹木葬」ではなく、「10年は個別に手を合わせたい。その後は合祀でいい」「いずれ子どもが引っ越すかもしれないので、取り出せる形にしておく」という、自分の事情に合った選び方ができます。

契約書で見る6つの項目

項目 確かめること
個別安置の年数 何年か。何回忌までか。延長できるか、延長の費用は
合祀の時期 個別安置が終わったあと、いつ、どこに合祀されるか
合祀後の取り出し できないことが明記されているか（できないのが普通）
年間管理料 あるか。いつまでか。滞納した場合の扱い
人数の追加 後から家族を追加できるか。追加の費用
宗旨宗派の条件 宗教不問か、檀家になる条件があるか。法要の形

パンフレットではなく、契約書（使用規則）で確かめてください。パンフレットに「永代供養」と書いてあっても、個別安置の年数は契約書にしか書いていないことがあります。

お参りできるか、実家の近くか、今住んでいる近くか

墓じまいの目的が「遠くて行けない」なら、新しい納骨先は今住んでいる場所の近くが自然です。ただ、家族の中に「先祖の土地に置いておきたい」という意見があることもあります。費用の内訳と手順を、ご家族で1枚に書き出して共有してから決めると、後の揉め事が減ります。

  1. 個別に安置したい年数を決める（0年＝最初から合祀、10年、33回忌まで、など）
  2. 場所を決める（今の住まいの近くか、先祖の土地か）
  3. その条件で、樹木葬・納骨堂・永代供養墓を見比べる
  4. 契約書の6項目を確かめる
  5. 今のお墓の管理者に埋蔵証明をもらい、今お墓がある市区町村へ改葬許可を申請する

改葬許可の申請で国の省令が必ず求めるのは、今のお墓の管理者が作る埋蔵（収蔵）の事実を証する書面です（施行規則2条2項1号）。新しい納骨先の受入証明は法定の添付書類ではなく、求めるかどうかは自治体によって違います。申請書には改葬先を書く欄があるので、納骨先が決まってから申請してください。

納骨先が決まると、墓じまいの総額が決まります。撤去の見積はその後で構いません。

まとめ

  • 樹木葬は形、永代供養は仕組み。永代供養が付いている樹木葬が多い（付いているかは施設ごとに違う）
  • 平均購入額は樹木葬71.7万円、納骨堂81.5万円、一般墓152.0万円（2026年調査）。合祀型は公営で1体5.3万円台から
  • 効くのは「個別安置の年数」と「合祀後は取り出せない」の2点。樹木葬でも最初から合葬の形がある
  • 契約書で6項目を確かめてから決める。納骨先が決まれば総額が決まる

墓じまい案内所は施工しません。納骨先の費用の幅と選び方、契約書で見る項目を一緒に整理し、お墓のある地域の石材店を最大3社まで手配します。納骨先との契約と、市区町村への改葬許可の申請はご自身で行っていただきます（申請の代理は行いません）。

よくある質問

永代供養なら本当に永久に供養してもらえますか

「永代」は「永久」ではなく、墓地が続く限り、という意味です。個別に安置する期間には期限があり（13回忌や33回忌まで、契約から10年、公営では20年など）、その後は合祀されるのが一般的です。契約書の「個別安置期間」を確かめてください。

夫婦や家族で同じ樹木葬に入れますか

何人入れるかは施設ごとに契約で決まっています。1人用・2人用・家族用と区分している施設があり、後から家族を追加できるか、追加のたびに費用がかかるかも施設ごとに違います。募集要項と契約書で確かめてください。

宗教や宗派の条件はありますか

お寺が運営する樹木葬・永代供養墓では、宗旨宗派を問わない所と、檀家になることが条件の所があります。公営の霊園は申込資格に宗教の条件がありません（都立霊園の募集要項）。民営や寺院は施設ごとに違うので、契約前に「宗教の条件」と「法要の形」を確かめてください。
